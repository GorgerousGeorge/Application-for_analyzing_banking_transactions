# Проект "Виджет операций"

## Описание
Проект будет готовить данные для отображения в консоли для аналитики списка банковских операций клиента

## Установка
1. Клонируйте репозиторий
2. Установите зависимости

## Использование
1. Разместите в папке data файл excel под названием "operations.xlsx" со списком банковских операций. У транзакций в этом списке обязательно должны быть указана информация в полях:
а) "Дата платежа" - дата совершения операции. String в формате "дд.мм.гггг"
б) "Сумма платежа" - сумма операции. Float
в) "Категория" - торговая категория в которой совершена операция, например "супермаркеты", "спорттовары", "переводы" и т.п. String
г) "Описание" - описание операции. String
*примечание: если вы хотите изменить путь к файлу или допустимое имя, измените имя переменной data_path в файле utils, указав там полный путь к файлу, который вы хотите открыть
2. Откройте приложение. Далее вы можете нажать на:
"1" - «События» - Пользователю необходимо задать диапазон данных, в котором он хочет проводить поиск ("W" -неделя, "M" -,месяц "Y" -год, "ALL" -весь период), после чего указать конечную дату интервала.Будет сформирован json-ответ и выведен в консоль с информацией о категориях расходов и пополнений, а
  также текущими курсами USD и стоимости акций из S&P 500
"2" - "Поиск" - Пользователь вводит фразу, приложение выводит в консоль информацию об операциях, в которых фраза клиента встречается в "Категория" или "Описание"
"3" - Траты по категориям" - Пользователю предлагается ввести название категории, после чего приложение формирует json-файл с информацией о тратах в этой категории за последние 3 месяца и сохраняет его по адресу reports\\Lastreport.json 

### Функции проекта:
- **main**: основная функция, в которой реализована основная логика взаимодействия приложения с пользователем через консоль
- - **events**: Функция, которая принимает на вход датафрейм с транзакциями, строку с датой и опционально строковый параметр, отвечающий за величину диапазона: W - неделя, на которую приходится дата, M - месяц, Y - год, ALL - все данные до указанной даты (по умолчанию берется месяц) и возвращает json с информацией о категориях расходов и пополнений, а также текущими курсами USD и стоимости акций из S&P 500
- - - **filter_data**: Функция, которая устанавливает диапазон дат. На вход принимает строку с конечной датой (в формате дд.мм.гггг) и строковый параметр, отвечающий за величину диапазона: W - неделя, на которую приходится дата, M - месяц, Y - год, ALL - все данные до указанной даты
- - - **calculate_expenses_and_income**: Принимает на вход датафрейм с транзакциями, начальную и конечную даты в строковом формате дд.мм.гггг. Возвращает: общую сумму расходов; список с 7 основными категориями расходов, отсортированных по убыванию; сумму расходов из категорий, не вошедших в 7 основных; сумму расходов в категориях "Переводы" и "Наличные"; общую сумму пополнений; список категорий в которых проходили пополнения с сортировкой по убыванию
- - - **currency_ratings**: Функция, которая возвращает текущий курс американского доллара к рублю и евро к рублю
- - - **stock_pricer**: """Функция, котрая возвращает курс акций из S&P 500"""
- - **transaction_finder**: Принимает на вход список словарей с банковскими транзакциями. Возвращает json со всеми транзакциями, содержащими пользовательский запрос в описании или категории.
- - **sending_by_category**: возвращает траты по заданной категории за последние три месяца от переданной даты в переданном датафрейме с транзакциями. Если дата не передана, то по умолчанию используется текущая
- - - **reportwriter**: Декоратор, который записывает в файл результат, который возвращает функция, формирующая отчет.
